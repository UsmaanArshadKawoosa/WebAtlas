# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this repository or its infrastructure, please report it by opening a private GitHub security advisory. We will investigate and respond as quickly as possible.

Please do not open public issues for security vulnerabilities.

## Supported Versions

As this is a resource directory repository, security concerns typically relate to:

- URLs that may have been compromised or changed
- Malicious or phishing resources submitted via PRs
- Data integrity of the resource database

## Response Process

1. Report the vulnerability privately via GitHub security advisory
2. Maintainers will investigate within 48 hours
3. Affected URLs or entries will be reviewed and removed if necessary
4. A security advisory will be published if warranted

## Security Best Practices for Contributors

- Never include API keys, tokens, or credentials in any file
- Verify URLs before adding them — ensure they point to legitimate sites
- Do not link to suspicious or unverified third-party resources
