# Taxonomy

This document defines the categories, subcategories, tags, and resource types used across WebAtlas.

## Categories

| Category | Description |
|---|---|
| Design Inspiration | Resources for discovering excellent website and UI design |
| UI Components | Reusable UI components and component libraries |
| Animation & Interaction | Animation and interaction resources |
| 3D & WebGL | Resources for 3D websites and interactive graphics |
| Colors | Tools for choosing and testing website colors |
| Typography | Resources for website typography |
| Assets | Website assets (images, illustrations, SVGs, etc.) |
| Icons | Icon libraries and icon tooling |
| Developer Tools | Tools that help developers implement designs |
| AI | AI tools relevant to website design and development |
| Design Systems | Resources for building consistent interfaces |
| Accessibility | Resources for accessible websites |
| Learning | High-quality learning resources |

## Tags

Tags are used for cross-cutting concerns. Common tags include:

| Tag | When to Use |
|---|---|
| React | Built for React |
| JavaScript | Built for JavaScript |
| Vue | Built for Vue |
| Tailwind | Uses Tailwind CSS |
| shadcn | Integrates with shadcn/ui |
| Animation | Involves animation |
| Motion | Uses Motion library |
| Open Source | Open source license |
| Free | Free to use |
| Components | Provides UI components |
| Blocks | Provides page blocks/sections |
| Templates | Provides templates |
| WebGL | Uses WebGL |
| 3D | Related to 3D |
| Color | Related to color |
| Typography | Related to typography |
| Tool | Utility/tool (vs library) |
| Gallery | Browse/curate design |
| Library | Reusable code library |
| Data Visualization | Charts/data viz |
| Particles | Particle effects |
| Interactive | Interactive elements |
| Icons | Icon resources |
| Design Systems | Design system tokens/guidelines |
| Accessibility | Accessibility focused |

## Resource Types

| Type | Description |
|---|---|
| Library | Reusable code library or collection of components |
| Tool | Utility or application for a specific task |
| Gallery | Curated collection for browsing |
| Template | Pre-built starting point for a project |
| Guide | Educational or instructional resource |
| Asset | Static resource (image, font, icon set) |
