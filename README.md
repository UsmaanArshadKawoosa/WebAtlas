# WebAtlas

> The open directory for discovering resources to design and build modern websites.

WebAtlas is a community-maintained, curated directory of high-quality resources for designing and building modern websites — from UI components and animations to design inspiration, typography, colors, and beyond.

## What is WebAtlas?

WebAtlas is a curated collection of resources for designers and frontend developers. Every entry is categorized, tagged, and structured so you can quickly find what you need. The project is open-source and community-driven.

## Who is it for?

- **Web designers** looking for design inspiration, color tools, typography resources, and UI building blocks
- **Frontend developers** seeking component libraries, animation tools, developer utilities, and learning materials
- **Creative technologists** exploring 3D, WebGL, and interactive experiences

## Philosophy

WebAtlas aims to be **curated, useful, and community-maintained**:

- **Curated** — Every resource is reviewed for quality. No link dumps.
- **Useful** — Resources must provide genuine value to designers or developers.
- **Community-maintained** — Anyone can suggest improvements via GitHub PRs.

## How to contribute

See [CONTRIBUTING.md](CONTRIBUTING.md) for detailed instructions. The basic process:

1. Find the appropriate category
2. Check whether the resource already exists
3. Verify the official URL
4. Add a concise description
5. Add appropriate tags
6. Submit a PR

## Data format

All resources are stored in structured JSON at [`data/resources.json`](data/resources.json) and represented in human-readable Markdown files under [`resources/`](resources/). See [docs/resource-schema.md](docs/resource-schema.md) for the full schema and [docs/taxonomy.md](docs/taxonomy.md) for categories, subcategories, and tags.
